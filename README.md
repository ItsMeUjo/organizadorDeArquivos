# organizadorDeArquivos

Como utilizar:

Abra o programa
Escolha uma pasta no seu computador que queira organizar
O programa criará 7 pastas dentro da que foi selecionada (Imagens, Audios, Documentos, Planilhas, CSVs, PDFs, Executáveis)
Cada pasta será povoada com o respectivo arquivo que deveria estar dentro dela
